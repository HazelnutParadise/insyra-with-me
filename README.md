# Insyra With Me

The Insyra community blog (Astro, static). `npm install`, then `npm run dev`. Docs: DESIGN.md, CONTENT-GUIDE.md, SEO-CHECKLIST.md, DEPLOY.md.

## Builds

- `npm run build`: dev/preview build, sample posts included.
- `npm run build:prod`: production build with no sample posts (`INCLUDE_SAMPLES=false`) and a check that fails if any sample would be published.
- See CONTENT-GUIDE.md ("Sample posts and drafts") for details.
